# MammothWP Acceptance Logs

[![License: GPL v2+](https://img.shields.io/badge/license-GPL--2.0--or--later-blue.svg)](https://www.gnu.org/licenses/gpl-2.0.html)
![PHP 8.1+](https://img.shields.io/badge/PHP-8.1%2B-777bb4.svg)
<!-- [![wordpress.org](https://img.shields.io/wordpress/plugin/v/mammoth-acceptance-logs.svg)](https://wordpress.org/plugins/mammoth-acceptance-logs/) -->

Log that your users accepted your terms. Versioned, role-scoped and
tamper-evident, with a permanent archive of every version.

- **Versioned archive** of every published text; versions are never deleted.
- **Tamper-evident log**: two signatures per record plus a hash chain, with a verifier.
- **Role-scoped prompt**: popup with "skip for now" and a persistent notice.
- **GDPR tooling**: exporter, eraser, retention anonymisation, privacy-policy text.
- **One definition, four surfaces**: admin, REST, WP-CLI and the Abilities API (via [wp-kit](https://packagist.org/packages/mammothwp/wp-kit)).
- Not consent management: an access-control and contractual-compliance record (GDPR Art. 6(1)(b), (f)).

Screenshots live in [`.wordpress-org/`](.wordpress-org/) (`screenshot-N.png`, regenerated by `bin/screenshots/`).

## Download and install

The wordpress.org listing is pending review. Until it is live, install from
this repository, as described on
<https://mammothwp.com/plugins/mammothwp-acceptance-logs/>:

1. Download the ZIP of `main` from GitHub (**Code → Download ZIP**).
2. Unzip it, rename the folder `admin-terms-acceptance-main` to
   `mammoth-acceptance-logs`, and zip that folder again.
3. In WordPress go to **Plugins → Add New → Upload Plugin**, choose the zip and
   install it.
4. **Activate** the plugin, then open **Settings → Terms & Conditions**.

The GitHub tree has no `vendor/` directory. The core acceptance flow works
without it, but the REST API, WP-CLI, the Abilities API, the Support screen and
PDF receipts need the dependencies. Run this inside the plugin folder before
zipping (or on the server):

```bash
composer install --no-dev --optimize-autoloader
```

Requires WordPress 6.2+ and PHP 8.1+. To build a distributable zip from a
checkout, use `composer build` (see Contributing).

## Usage

Full details in [`docs/usage.md`](docs/usage.md).

| Surface | Example |
|---|---|
| Admin | Settings → Terms & Conditions; Users → Terms acceptance log |
| REST | `GET /wp-json/mmwp/v1/terms/acceptances?version_id=3` (plugin managers) |
| WP-CLI | `wp mmwp terms publish --content="$(cat terms.html)" --only-if-changed` |
| Abilities | `mmwp-acceptance-logs/list-acceptances` (read-only) |

Use the support forum on wordpress.org, or e-mail info@mammothwp.com. The

## Contributing

```bash
composer install
composer lint          # phpcs (WPCS + PHPCompatibilityWP) and phpstan
bin/install-wp-tests.sh wordpress_test root '' 127.0.0.1 latest
composer test:phpunit
mmwp-release build           # zip from .distignore, for Plugin Check
```

Several rules (append-only evidence, frozen signature field orders, no edit or
delete affordance in the admin) are load-bearing; see `docs/`.
